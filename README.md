### Padel App 🎾

A modern **Flutter-based Padel Court Booking Application** designed to provide users with a simple and seamless way to discover padel courts, explore available time slots, and manage their reservations.

**Key Features**

* 🎾 Browse and explore padel courts
* 📅 View available booking slots
* 🏟️ Court reservation management
* 👤 User-friendly interface
* 📱 Cross-platform Flutter application
* 🎨 Clean and modern UI
* ⚡ Smooth and responsive user experience

**Tech Stack**

* Flutter
* Dart
* Material Design

**Project Goal**

The goal of this project is to create a convenient digital platform for padel players to discover courts and manage their bookings through a modern, intuitive, and responsive mobile application.
